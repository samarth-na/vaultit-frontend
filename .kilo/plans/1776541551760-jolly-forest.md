## Current State Analysis

### Existing Setup

- **Routing**: React Router DOM v7
- **Theme**: OKLCH color space with dark mode via `.dark` class (already configured in `src/index.css`)
- **Components Created**:
  - `src/pages/Notes.tsx` - Main page
  - `src/components/notes/NotesSidebar.tsx` - Sidebar
  - `src/components/notes/NotesEditor.tsx` - Editor

### Issues to Address
1. No theme switching mechanism (user can't toggle light/dark)
2. Notion-like color palette not applied (currently generic OKLCH values)
3. Missing Notion-specific styling details (warm neutrals, typography, spacing)
4. Sidebar styling not aligned with Notion's aesthetic

## Research Summary

### Notion Design System
From research findings, Notion's key characteristics:

**Light Mode Palette:**
- Background: `#FFFFFF` (warm white)
- Sidebar: `#F7F6F3` (signature warm hover/surface)
- Text primary: `#37352F` (warm brown-black, NOT pure black)
- Text secondary: `#787774`
- Borders: `rgba(55, 53, 47, 0.09)` (subtle, warm gray)
- Accent: `#2383E2` (muted blue, not flashy)
- Hover state: `#F7F6F3` (used extensively)

**Dark Mode Palette:**
- Background: `#2F3437` (main window)
- Sidebar: `#373C3F`
- Text: `#FFFFFF` / `rgba(255,255,255,0.9)`
- Hover: `#3F4448`

**Typography:**
- Font: Inter (or Source Sans 3)
- Body: 16px / 400
- Line height: ~1.6 for readability
- Character: Warm, approachable, not clinical

**Core Principles:**
- Warm neutrals over cold colors
- Generous spacing
- Minimal accent visibility
- High comfort for long reading sessions
- "Quiet" UI that doesn't demand attention

## Technical Decisions

### Theme Strategy
- **Class-based** (`dark` class on `<html>`): Matches existing setup, works well with Tailwind v4
- Persist to `localStorage` key: `vaultit-theme` ("light" | "dark")
- Respect system preference on first visit (no localStorage value)
- Inline script in `index.html` to prevent FOUC (already possible with Vite)

### Icons
- Check if `lucide-react` or similar is installed (likely not)
- Use remixicon (already in project via `@remixicon/react`) for theme toggle
- Import: `import { Icon } from '@remixicon/react'` → `<Icon name="ri-sun-line" />` / `<Icon name="ri-moon-line" />`

### Typography
- Existing `Raleway` variable font is excellent for Notion aesthetic (clean, humanist)
- Use `font-sans` everywhere for consistency
- Editorial approach: Title tall and light, body comfortable and readable

### Spacing Scale
- Notion uses 4px base grid
- Sidebar item padding: `px-3 py-2` (12px 8px)
- Editor padding: `p-6` (24px)
- Gap between items: `gap-1` (4px)

### Accessibility
- All interactive elements focus-visible
- Contrast ratio check
- Screen reader labels on icon-only buttons
- Keyboard shortcuts documented (Ctrl+N)

## Risks & Mitigation

| Risk | Impact | Mitigation |
|------|--------|------------|
| Theme affects other pages unexpectedly | Medium | Theme is global; ensure all pages use theme variables |
| localStorage quota exceeded (notes + theme) | Low | Both items small; ~5KB max total |
| Performance hit from frequent localStorage writes | Low | Notes persist on every change; could debounce but current is fine for small use |
| Dark mode colors not accessible enough | High | Verify contrast ratios, adjust as needed |
| Existing shadcn components have hardcoded colors | Medium | Override with CSS custom properties where needed |
