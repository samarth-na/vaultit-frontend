# Notes Page Migration Plan: Custom → shadcn/ui

## Current State Analysis

### Existing Structure
- **Route**: `/notes` → `src/pages/Notes.tsx`
- **Components**: 
  - `NotesSidebar` (custom, uses shadcn Button + custom buttons)
  - `NotesEditor` (custom, uses shadcn Textarea)
  - `ThemeToggle` (already shadcn-based)
- **Styling**: Tailwind classes with theme CSS variables
- **Icons**: RemixIcon (`@remixicon/react`)
- **State**: localStorage persistence, localStorage hooks

### Components Already Using shadcn/ui
- ✅ Button (in NotesSidebar "New Note" button)
- ✅ Textarea (in NotesEditor)
- ✅ ThemeToggle uses Button component

---

## Migration Goals

### 1. Migrate Custom Elements → shadcn/ui

#### NotesSidebar Improvements
| Current | Target |
|---------|--------|
| Custom `<button>` for note items | Use `Card` as clickable note item |
| Empty state custom div | Use `Card` as empty state container |
| "New Note" button | Already using `Button` - keep with variant |
| No separator between header & list | Add `Separator` component |
| Icon-only buttons | Keep, but with proper accessibility |

**Proposed Changes:**
- Wrap note item in `Card` with appropriate padding, hover states
- Use `CardHeader` for note title line, `CardDescription` for preview
- Add `Badge` showing "No notes" in empty state or note count
- Add `Separator` below header
- Ensure `Card` has `cursor-pointer` and proper `role="button"`

#### NotesEditor Improvements
| Current | Target |
|---------|--------|
| Simple div header | Use `Card` for header with icon + title |
| Empty state custom div | Use `Card` centered as empty state |
| Textarea container | Already using `Textarea` - keep, maybe wrap in `Card` |
| Icon RemixIcon | Keep RemixIcon, shadcn doesn't provide icons |

**Proposed Changes:**
- Wrap editor header in `Card` component for visual separation
- Empty state: Use `Card` with centered content
- Add `Badge` for word count or character count (optional enhancement)
- Add `Separator` in header or metadata area

### 2. Unique Visual Identity (Background & Colors)

#### Color Palette Strategy
Create a distinctive "Notes" theme by introducing CSS custom properties that override the default theme for this page only.

**Approach**: Scoped CSS custom properties on the Notes page container.

**Proposed Color Scheme:**
- **Primary accent**: Warm coral/terracotta (different from app's sky blue)
  - Example: `#F97316` (orange-500) or `#F59E0B` (amber-500)
- **Background**: Subtle gradient mesh pattern
- **Sidebar**: Slightly darker tint with pattern overlay
- **Editor**: Light textured background with subtle grid

#### Background & Visual Effects
1. **Mesh Gradient Background** (applied to Notes page container):
   - Use CSS radial gradient blobs with blur
   - Colors: Coral/Amber/Yellow mix
   - Animated subtle movement (optional CSStransitions)

2. **Sidebar Pattern**:
   - Subtle dot or grid pattern overlay (using CSS repeating-linear-gradient)
   - Slightly different shade to distinguish from editor

3. **Editor Canvas**:
   - Paper-like texture (subtle grain or line pattern)
   - Or clean with corner fold effect (optional)

4. **Note Cards**:
   - Unique border radius/shadow
   - Hover effects: scale, shadow elevation

#### Implementation Options

**Option A: Scoped CSS Variables (Recommended)**
```css
/* Add to index.css */
.notes-page-container {
  --notes-primary: #F59E0B;        /* amber-500 */
  --notes-primary-foreground: #FFFFFF;
  --notes-accent: #F97316;         /* orange-500 */
  --notes-background: #FFFBEB;     /* amber-50 */
  --notes-sidebar-bg: linear-gradient(135deg, #FFFBEB 0%, #FEF3C7 100%);
  --notes-editor-bg: #FFFFFF;
  --notes-mesh-1: rgba(249, 168, 37, 0.15);
  --notes-mesh-2: rgba(251, 146, 60, 0.1);
  --notes-mesh-3: rgba(254, 215, 170, 0.2);
}
```
Then apply classes throughout Notes components.

**Option B: New Component-Level Theme**
Create `NotesTheme` context provider that overrides CSS variables locally.

**Option C: Direct Override Classes**
Add Tailwind arbitrary values like `bg-[#FFFBEB]`, `border-[#F59E0B]`.

### 5. Accessibility & UX Improvements

1. **ARIA Labels**:
   - Add `aria-label` to custom note buttons (e.g., `"Note: Untitled"`)
   - Badge for empty state: `aria-live="polite"`

2. **Focus States**:
   - Ensure Card focus-visible ring works with Tab navigation
   - Add `tabIndex={0}` to Card notes

3. **Keyboard Navigation**:
   - Notes already supports ← → ? Better with Card
   - Arrow up/down navigation between notes

4. **Screen Readers**:
   - Add `aria-selected` on active note
   - Announce note count in header (optional)

## Implementation Steps

### Phase 1: Refactor Components (shadcn/ui Only)
1. Update `NotesSidebar.tsx`:
   - Replace note list `<button>` with `<Card>` + `onClick`

### Phase 3: Polish
1. Add subtle transitions and hover effects (scale, shadow)
2. Ensure focus rings use notes theme color
3. Add custom scrollbar styling (optional)
4. Verify light/dark mode compatibility with new colors

## Notes & Considerations
- The user prefers minimal comments in code (per agent guidelines)
- All changes should preserve existing behavior (localStorage, shortcuts)
- ThemeToggle is positioned absolute - keep it above backgrounds
- Mesh gradient animation may impact performance on low-end devices; can add prefers-reduced-motion media query
- Consider using `backdrop-filter` for frosted glass effect if desired
